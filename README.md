# THE_DEN — نموذج موقع تجريبي

نموذج عرض لموقع نادي ذا دِن الرياضي (الرس). ليس الموقع الرسمي للنادي.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## ملاحظات

- المحتوى في `src/data/club.js`، ويتعدل من لوحة المالك على `#/admin`.
- الحفظ في نسخة العرض على متصفح الجهاز فقط (`src/store.js`).
- الصور والفيديو من Pexels، وأسعار المتجر والبرامج أمثلة إلى أن يعتمدها النادي.
